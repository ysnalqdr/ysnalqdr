## How I work

- **No week without a commit.** Consistency over bursts — 48 weeks, not 4 sprints.
- **20% reading, 80% typing.** Never copy-paste. If I can't write it from zero, I don't know it.
- **A gate every day.** Explain back in 5 lines, predict 3 outputs, write 1 exercise from scratch.
  Pass 2 of 3 or repeat the day. Understanding beats speed.
- **Mistakes get logged, not deleted.** Wrong code is commented out with one line saying why.
  Anything I get wrong three times needs a different approach, not more effort.
